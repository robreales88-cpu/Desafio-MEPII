# SVG

Gráficos vectoriales reutilizables: figuras del componente Matrix, iconos de proceso, patrones. Ver `/content/docs/CONTENT_GUIDE.md`, sección 6, para la convención de nombres y cómo referenciarlos desde un JSON (`svgRef`).

Mantén los SVG simples (formas, iconos) — no incrustes imágenes fotográficas como SVG.
