# Icons

Iconos rasterizados (instrumentos, herramientas, categorías). Ver `/content/docs/CONTENT_GUIDE.md`, sección 7, para la convención de nombres y cómo referenciarlos desde un JSON (`imageRef`).

Prefiere SVG (`/content/media/svg/`) cuando el ícono sea una forma simple — usa esta carpeta para iconos que requieran detalle fotográfico o que ya vengan en formato rasterizado.
